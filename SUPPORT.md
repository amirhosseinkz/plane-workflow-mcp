# Support

## Where to ask

- Use GitHub Discussions, when enabled, for setup questions, usage ideas, and
  general community help.
- Use the issue forms for reproducible bugs and focused feature requests.
- Follow [SECURITY.md](SECURITY.md) for vulnerabilities. Do not disclose them
  publicly.

## What to include

For setup or bug reports, include the package version, operating system,
client, sanitized command output, and a minimal reproduction. Remove API keys,
private URLs, workspace or project identifiers, generated reports, and other
organization-specific information before posting.

## What maintainers can support

Maintainers can help with documented public releases and supported
configuration paths. Custom integrations, self-hosted infrastructure, and
private Plane deployments may require community discussion or local expertise.
